# zorzo-site

Static front of [zorzo.dev.br](https://zorzo.dev.br), the professional site of André de Castro Zorzo, where
visitors question an AI agent about his work and watch each answer being produced.

The backend, the API contract and the system-wide design docs live in
[zorzo-api](https://github.com/andrezorzo/zorzo-api).

Status: design phase. No code yet.
